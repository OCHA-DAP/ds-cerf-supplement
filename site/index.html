The public OneGMS feeds behind CERF and the Country-Based Pooled Funds, mirrored daily into the team database, plus what we add on top: which storm each CERF storm allocation responded to, and the months of rainfall deficit behind each drought allocation.

Every Rapid Response storm allocation matched to its IBTrACS storm(s), and every drought allocation dated to the months of the actual meteorological drought — searchable, sortable, with confidence and notes, and a CSV download. Regenerated from the database after each daily matching run.

The pipeline: daily refresh of the CERF allocation and project mirrors (aa.cerf_*), the CBPF mirrors (aa.cbpf_*, schema cbpf), the storm and drought matchers, and the deploy of this site. The README documents every table and the API quirks the mirror absorbs.
